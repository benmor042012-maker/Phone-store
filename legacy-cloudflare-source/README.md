# Phone Store

חנות הסלולר של אלי חזות בנתניה — [phonestore.co.il](https://phonestore.co.il/).

אתר עברי (RTL) בעמוד יחיד, בלי build step: כל הדף הוא `public/index.html`,
וה-Worker (`src/worker.js`) מוסיף את מה שאחסון סטטי לא יודע לעשות — בדיקת
סיסמת האדמין מול secret, פרסום תוכן ל-KV, והזרקת התוכן וה-SEO לדף המוגש.

**מודל המכירה מכוון:** אין סליקה ואין קופה. הסל בונה הודעת וואטסאפ מסודרת
והעסקה נסגרת בשיחה. אל תוסיפו מערכת תשלומים בלי החלטה מפורשת של הלקוח.

## מבנה

| קובץ | תפקיד |
|---|---|
| `public/index.html` | האתר כולו: עיצוב, תוכן ברירת־מחדל (`DEFAULTS`), קטלוג, סל, פאנל ניהול |
| `src/worker.js` | לוגין אדמין, `GET/PUT /api/data`, הזרקת תוכן ומטא, `/product/:id`, sitemap, robots |
| `public/_headers` | כותרות אבטחה כולל CSP |
| `wrangler.jsonc` | קונפיגורציית Cloudflare Workers |

## פיתוח מקומי

```bash
npm install
echo 'ADMIN_PASSWORD=בחרו-סיסמה' > .dev.vars   # הקובץ ב-.gitignore
npx wrangler dev
```

ל-KV מקומי (סימולטור, בלי חשבון): בטלו זמנית את ההערה על בלוק
`kv_namespaces` ב-`wrangler.jsonc` עם id כלשהו (למשל `"local"`) — **בלי
לקמט את זה**; בפריסה אמיתית id מומצא מפיל את ה-build.

## פריסה והפעלה ראשונית (go-live)

הפריסה רצה אוטומטית ב-Workers Builds על push לענף שמוגדר בדשבורד.

צעדי ההפעלה החד־פעמיים **בוצעו ב-18/08/2026**: ה-secret ‏`ADMIN_PASSWORD`
מוגדר, ה-namespace ‏`STORE` קיים (ה-id ב-`wrangler.jsonc`), וה-KV הוזן
בתוכן הפתיחה. לשחזור בחשבון אחר:

1. **סיסמת אדמין:** `npx wrangler secret put ADMIN_PASSWORD`
   (רשות: גם `ADMIN_TOKEN_SECRET`, אחרת הטוקן נחתם עם הסיסמה).
2. **מחסן תוכן:** `npx wrangler kv namespace create STORE`, ואז לעדכן את
   ה-id בבלוק `kv_namespaces` ב-`wrangler.jsonc`, לקמט ולדחוף. בלי binding
   האתר עובד רגיל על תוכן ברירת המחדל, והאדמין שומר בדפדפן בלבד.
3. **פרסום ראשון:** להיכנס ל"ניהול תוכן" באתר החי וללחוץ "פרסום עכשיו"
   (או לשמור כל דבר). זה מזין את ה-KV — מרגע זה כל גולש רואה את התוכן
   המנוהל, ועמודי `/product/:id` מקבלים מטא ו-JSON-LD פר־מוצר.

## איך עובד ניהול התוכן

- כל שמירה בפאנל נשמרת קודם **כטיוטה** בדפדפן, ומתפרסמת לשרת אוטומטית
  אחרי ~3 שניות (debounce, בגלל מגבלת כתיבה של KV), או מיד בכפתור
  "פרסום עכשיו". התג ליד הכותרת מראה את המצב.
- פג תוקף החיבור (8 שעות)? חוזרים לשער הסיסמה, הטיוטה נשמרת — נכנסים
  ולוחצים "פרסום עכשיו".
- **שחזור חד־צעדי:** המעטפת הקודמת נשמרת ב-KV תחת `site:data:v1:prev`.
  שחזור ידני: `npx wrangler kv key get --binding STORE site:data:v1:prev`
  ואז `put` בחזרה למפתח `site:data:v1`. קובצי הגיבוי (JSON) מהפאנל הם
  הרשת השנייה — להוריד אחרי כל עדכון גדול.
- צורת הנתונים: מעטפת `{schema:1, updatedAt, data:{settings,slides,cats,products,reviews}}`.
  שינויים מוסיפים לא דורשים גרסה חדשה — `normalizeData()` בדף מתקן
  ומשלים בכל טעינה. שינוי שובר צורה עובר ל-`site:data:v2` עם fallback.

## שפות, תמה ותמונות

- **שפות:** חזית האתר בעברית, אנגלית, צרפתית ורוסית — מתג בהדר, הבחירה
  נשמרת, ו-`?lang=fr` פותח קישור בשפה מסוימת (שימושי לשליחה ללקוח).
  מתורגם רק הממשק; שמות ותיאורי מוצרים נשארים כפי שהוזנו, ופאנל הניהול
  נשאר בעברית. להוספת מחרוזת: מפתח חדש ב-`I18N` (סעיף 2b ב-index.html)
  ו-`data-i18n="key"` במרקאפ, או `t('key')` ב-JS.
- **תמה:** כהה כברירת מחדל, בהיר במתג שבפאנל הנגישות. רק ערכי הטוקנים
  מתחלפים (בלוק `:root[data-theme="light"]`). ההירו, פס התהליך, הסרגל
  העליון והפוטר נשארים כהים בשתי התמות — החלטת עיצוב.
- **תמונות מוצר:** בפאנל הניהול, "העלאת תמונה" מעלה קובץ מהמחשב. הדפדפן
  מקטין ל-WebP ברוחב 1200px, ה-worker שומר ב-KV תחת `img:<id>` ומגיש
  מ-`/img/<id>`. תקרה 2MB, סוגים מותרים: webp/jpeg/png. תמונה שהוחלפה
  נשארת ב-KV (עלות זניחה); ניקוי ידני:
  `npx wrangler kv key list --binding STORE --prefix img:`.

## SEO

- לכל מוצר יש כתובת אמיתית `/product/:id` עם title/OG/canonical ו-JSON-LD
  מסוג Product+Offer מוזרקים בשרת; `/sitemap.xml` ו-`/robots.txt` נוצרים
  מהתוכן המפורסם.
- JSON-LD של העסק (ElectronicsStore) מתעדכן מהגדרות הפאנל.
- אין AggregateRating בכוונה — הביקורות ברמת החנות ולא מאומתות.

### משימות תוכן פתוחות (לקוח)

- **צילום מוצרים אמיתי** — התמונות הנוכחיות הן סטוק גנרי
  (ראו `public/assets/products/CREDITS.md`).
- **תמונת שיתוף 1200×630** ממותגת להחלפת ה-placeholder של `og:image`
  ב-`index.html`.
