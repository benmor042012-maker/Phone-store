# scripts

`render-hero-video.py` renders `client/public/hero-phone-store-iphone18.mp4`, the iPhone 18 Pro
loop behind the storefront hero, in the site's black-and-gold palette.

```bash
pip install pillow numpy imageio-ffmpeg
python3 scripts/render-hero-video.py client/public/hero-phone-store-iphone18.mp4
```
